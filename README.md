One single line of text — the Moon's answer to everyone who has ever stared up at it:

> I heard every wish. I am still here, and I am still not granting any of them.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

`main.ts` (Node 22, stdlib only) reads `entry.txt` and writes it unchanged to `output.txt` inside the output directory.
